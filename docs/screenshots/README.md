# Screenshots

These screenshots are generated from the local Studio web and desktop
applications with the safe files in `samples/` and the desktop's generated
certificate example. They contain no production
endpoint, credential, or customer data.

The desktop home and workspace images are captured by the existing JavaFX
smoke test when `-Dpdf.batch.screenshots=/absolute/output/directory` is supplied
to Maven. A graphical display or Xvfb is required.
